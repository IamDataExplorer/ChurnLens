## Dataset

The dataset used in this project is publicly available on Kaggle.

📥 **Download here:**
https://www.kaggle.com/datasets/rangalamahesh/bank-churn/data?select=train.csv

After downloading, place `train.csv` in this `/data` folder before running the notebooks.

**Dataset details:**
- 165,034 rows × 14 columns
- Source: Uploaded by Rangala Mahesh on Kaggle
- File needed: `train.csv`
